# 项目任务: 格局系统升级 (Tasks)

## 第一阶段: 基础架构与数据

- [ ] **数据结构设计**: 确定 Pattern 和 Definition 的 JSON Schema。
- [ ] **迁移脚本**: 编写脚本将现有的扁平 JSON 文件转换为新的拆分结构 (Index vs Definitions)。
- [ ] **通用标记**: 识别并标记现有数据中的通用格局。

## 第二阶段: 核心引擎

- [ ] **解析服务**: 实现“选择器”逻辑 (用户 > 流派 > 通用)。
- [ ] **DSL 实现**: 重构当前的条件解析器，支持标准的 DSL 功能码。
- [ ] **引擎更新**: 确保引擎能够接收并执行原始的 Definition JSON 对象。

## 第三阶段: 用户自定义 (后端/存储)

- [ ] **UGC 存储**: 创建用户定义的本地存储机制 (例如通用文件或独立 DB 表)。
- [ ] **Forking 逻辑**: 实现 API，支持将系统定义克隆为用户定义。

## 第四阶段: UI 与交互

- [ ] **流派切换**: 添加 UI 以在不同流派之间切换。
- [ ] **格局详情页**: 更新以显示来源元数据 (Source Metadata)。
- [ ] **注解 UI**: 用于添加/编辑文本笔记的界面。
- [ ] **逻辑构建器 (未来)**: 用于自定义逻辑的可视化编辑器。
