## Proof Levels

- **Runtime proof:** a real module adapter and executable tests exist.
- **Source-shape proof:** real module fields/widgets were inspected and mapped to neutral contracts; no adapter is claimed.
- **Design proof:** the required contract is specified but remains a later implementation task.

P0 validates model expressiveness. P0.11 separately prevents source-shape or
design proof from being misrepresented as a production migration.

## Required Edge Cases

### Composite content (`ItemGroup`)

The real ZiWei `PalaceCard` source at
`xuan-ziweidoushu/lib/presentation/views/chart_detail/widgets/palace_card.dart:145-171`
iterates main stars, minor stars, and SiHua badges inside one palace. These
children share one palace identity and therefore map to one `ItemGroup`; this
is a source-shape proof, not a claim that a ZiWei adapter already exists.

### Dual-angle stars (`AngularPoint`)

`qizheng_chart_board_adapter.dart:134-151` reads each real star snapshot's
`originalAngle` and `resolvedAngle` and emits `AngularPoint`. This is runtime
adapter proof.

### Inner/outer mirror rings

`beauty_view_page.dart:1009-1048` supplies separate inner/outer track and body
builders. The design maps them to ordered overlays sharing one continuous ring,
with independent offset/direction/radial-anchor behavior. `RingOverlaySpec`
remains a P1.4 design contract; P0 proves the source shape and required fields,
not that the current package renderer has completed this behavior.

### Center and zero-width identity

`BoardCenterSpec` and `SkippedRingGeometry` exist in package commit
`ea37cd7c85fd`; executable integration into all renderers remains governed by
the later P1/P3 tasks. Their existence must not be used to mark those later
tasks complete.

## Renderer-Branch Check

The mappings select neutral layout/layer/behavior data. None requires a
renderer condition on `ModuleId`. Module-specific conversion remains in each
adapter, while Canvas and Widget renderers consume the same neutral board.

## Verdict

**PASS for P0 expressiveness, not multi-module production readiness.** The five
real source shapes and the required composite/dual-angle/mirror cases have an
explicit neutral representation. Only QiZhengSiYu has runtime adapter proof;
the executable P0.11 gate blocks any second production consumer until a real
multi-module conformance suite exists and passes.
