### 锚点提取（环链自洽，已验证）

| 宫 | 起点（0°）宿度 | 该宫合计 |
|---|---|---|
| 子（玄枵） | **虚 1.6275°** | 虚8.6275+危18+室3.8105 = **30.4380** |
| 亥（娵訾） | 室 3.8105° | 室13.1895+壁10+奎7.2484 = 30.4379 |
| 戌（降娄） | **奎 7.2484°** | 奎10.2516+娄13+胃7.1863 = 30.4379 |
| 酉（大梁） | 胃 7.1863° | 胃7.3137+昴11+毕12.1242 = 30.4379 |

- **子宫0° = 虚1.6275°**、**戌宫0° = 奎7.2484°**（1-D 锚点定案值）。
- 环链首尾衔接无缝（子终室3.8105 = 亥起；亥终奎7.2484 = 戌起；戌终胃7.1863 = 酉起）。
- 胃总宽 7.1863+7.3137 = 14.5°，对上歌诀"胃垣十四半"，佐证 decimal 表准确。
