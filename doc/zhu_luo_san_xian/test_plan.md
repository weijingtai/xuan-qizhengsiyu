# 竹罗三限 Test Plan

## 目标

验证竹罗三限可配置算法能稳定复现 A 法和 B 法，并保留扩展 C、D 的空间。

统一口径：

```text
所有测试使用虚岁 1 起的连续年表。
古文节点标注只用于解释，不直接作为测试年龄口径。
```

## 测试环境

按项目实际语言选择测试框架。若实现于 Dart，使用：

```text
flutter test
```

## 基础表测试

用例：

```text
巳酉丑 + 昼生 => 金、月、火
巳酉丑 + 夜生 => 月、金、火
寅午戌 + 昼生 => 日、木、土
申子辰 + 夜生 => 水、土、木
```

星数：

```text
月=1，水=1，日=2，火=2，木=3，金=4，土=5
```

限程：

```text
月=24，水=24，日=28，火=28，木=30，金=26，土=26
```

## 宫位移动测试

用例：

```text
move(巳, -2) = 卯
move(卯, -2) = 丑
move(寅, 1) = 卯
move(亥, 1) = 子
move(子, -1) = 亥
forwardDistance(未, 子) = 5
```

## A 法测试

配置：

```text
classic_inverse_sections
```

用例：土在巳。

期望：

```text
1-5 岁：巳
6-15 岁：卯
16-25 岁：丑
26 岁：寅
```

重点断言：

```text
age 5 = 巳
age 15 = 卯
age 25 = 丑
age 26 = 寅
```

## B 法测试

配置：

```text
direct_annual_with_bridge
```

用例：金在寅。

期望：

```text
1-4 岁：寅
5 岁：卯
6 岁：辰
7 岁：巳
```

重点断言：

```text
age 4 = 寅
age 5 = 卯
age 7 = 巳
```

## 腓特烈样例测试

输入：

```text
命宫：酉
昼夜：昼生
金星：寅
月亮：午
火星：子
算法：direct_annual_with_bridge
```

期望：

```text
三限主 = 金、月、火
19 岁 = 巳
29 岁 = 卯
32 岁 = 午
46 岁 = 申
47 岁 = 申
54 岁 = 子
55 岁 = 子
61 岁 = 午
75 岁 = 申
```

交限重叠断言：

```text
54 岁只能有 1 条记录
55 岁只能有 1 条记录
54、55 岁 palace = 子
54、55 岁 usedBridge = true
54 或 55 岁至少一个 isTransitionYear = true
```

## 分叉测试

同样输入：

```text
金在寅，金数 4，金限 26
```

A 法和 B 法必须不同：

```text
A 法 19 岁 != 巳
B 法 19 岁 = 巳
```

目的：

```text
防止实现时把 A、B 混成一套。
```

## 禁止项

- 不准用人工截图验算代替自动测试。
- 不准只测腓特烈案例。
- 不准把 A 法的“逆数三宫”写成 offset -3。
- 不准让测试依赖当前日期。
- 不准重复定义项目已有十二宫枚举。
- 不准新增或导入带 `xuan_` 前缀的新依赖。
