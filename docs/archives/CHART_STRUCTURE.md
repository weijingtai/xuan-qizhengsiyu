# 星盘物理结构 (Chart Physical Structure)

> 本档案总结了《七政四余盘制.pdf》中关于星盘基础物理构成的规则。

## 1. 十二宫 (Twelve Palaces)
星盘分为固定十二宫，按逆时针方向排列：
1. **命宫** (Life Palace)
2. **财帛宫** (Wealth)
3. **兄弟宫** (Siblings)
4. **田宅宫** (Home)
5. **男女宫** (Children)
6. **奴仆宫** (Servants)
7. **夫妻宫** (Marriage)
8. **疾厄宫** (Health)
9. **迁移宫** (Travel)
10. **官禄宫** (Career)
11. **福德宫** (Fortune)
12. **相貌宫** (Appearance)

## 2. 十二星次与二十八宿
盘制中星次与黄道十二宫对应：
- **子** (玄枵), **丑** (星纪), **寅** (析木), **卯** (大火), **辰** (寿星), **巳** (鹑尾), **午** (鹑火), **未** (鹑首), **申** (实沈), **酉** (大梁), **戌** (绛娄), **亥** (娵訾)。

二十八宿分布于十二星次之中，具体度数规则详见 PDF 第 15-28 页。

## 3. 度数定义
- 盘制采用 **360度** 黄道制。
- 每一星次占 **30度**。
- 支持 **分、秒** 级精度推算。
