# 起例与推算规则 (Construction & Calculation Rules)

> 本档案总结了《七政四余盘制.pdf》中关于如何起盘与推算的算法逻辑。

## 1. 命宫起例 (Life Palace Construction)
命宫的确定是起盘的第一步，PDF 提供了基于太阳位置与生时的推算方法：
- **公式**: `(太阳所在星次 + 生时) - 卯 = 命宫所在星次` (简化描述)
- **注意**: 盘制中需考虑冬至、夏至对度数的影响。

## 2. 星辰落宫 (Star Positioning)
- **七政**: 太阳、太阴、金、木、水、火、土。
- **四余**: 紫炁、月孛、罗睺、计都。
- **推算**: 需依据 Swiss Ephemeris (或传统历书) 计算当日各星精确黄道度数。

## 3. 大限推算 (Time Periods)
- 采用 **洞微大限** 算法。
- 起始位置由命宫度数决定。
- 每一大限跨度不同，具体年数分布见 PDF 第 42 页表格。
