# companion_system

七政四余格局数据维护系统

## 定位说明

`companion_system` 是七政四余主工程的伴生复合工具，用于格局数据维护、规则整理、导入导出、AI 辅助识别等辅助流程。它不是当前主线开发重点，也不应作为七政四余核心排盘、格局计算、四余算法或主应用质量门的判断依据。

主线功能以仓库根目录下的 `lib/`、`test/`、`example/` 以及相关领域文档为准；`companion_system` 中的历史实验、缺失生成物或未完成模块应按辅助工具债务单独处理。
