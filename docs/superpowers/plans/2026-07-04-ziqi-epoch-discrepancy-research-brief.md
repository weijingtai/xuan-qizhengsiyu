## 0. 背景（零上下文读者必读）

**七政四余**是中国传统星命体系：七政 = 日月 + 水火木金土五星；四余 = 紫气、月孛、罗睺、计都四颗「虚星/余曜」。

**紫气（紫炁）** 的特殊性：它**没有对应的真实天体**（月孛=月球远地点、罗计=月球升降交点，都有天文对应；唯紫气是纯历法虚星）。因此紫气位置**只能靠「历元 + 匀速平行推算」**得到：

```
紫气位置(t) = 历元位置 + 日行度 × (儒略日(t) − 历元儒略日)   ，再对周天取模
```

其绝对相位完全依赖**历元校准**，这正是本次调研的核心。

本项目支持**多套坐标系（星制）**。同一颗星在不同星制下的「宿度/宫度」表达不同。**本次矛盾明确发生在下述唯一一个星制 + 唯一一套紫气算法下**（见 §1），请勿引入其它星制混淆。

## 1. 矛盾锁定的星制与紫气算法（务必精确对齐）

### 1.1 星制：元授时·天赤道恒星制

| 项 | 值 |
|---|---|
| 基准平面 | **天赤道**（非黄道） |
| 周天总度 | **365.25 赤道古度**（非 360°；一年之数，太阳日行约一度） |
| 二十八宿坐标 | **永久固定，不随岁差偏移**（恒星制）；只有日月五星四余星体带岁差移动，宿度不动 |
| 宿距数据源 | **郭守敬《授时历》实测二十八宿赤道距度**（即郑氏星案原版配套「古宿尺」，见 §2.1） |
| 十二宫 | 沿赤道均分，以**虚宿 6 度定子宫中点**（等价 alignmentPointAtGong = 丑宫 15°） |
| 零点节气 | 冬至 |

### 1.2 紫气算法：果老/授时「女宿历元」积日平行顺推

| 常数 | 值 | 备注 |
|---|---|---|
| 运动 | 匀速、**顺行**、无留逆 | |
| 周期 | **28 恒星年 = 10227.1792 日** | 待核：另有 29 年制 = 10592 日之异说 |
| 日行 | **365.25 / 10227.1792 ≈ 0.0357143 赤道古度/日** | = 古法「3 分 57 秒 14 微」= 13.050460 古度/年（授时百进制度分秒） |
| 历元时刻 | **1280-12-14 01:29:36**（授时辛巳岁前天正冬至） | 待核历法（儒略/公历/农历） |
| 历元紫气位置 | 传统称「**女宿二度**」（约当赤道经度，精值即本次要反解者） | |

> **关键**：日行必须用 **365.25/周期**（赤道古度），归一化 **mod 365.25**。切勿误用 360° 制的 0.0352°/日，也勿把 0.0357 古度直接对 360 取模——那是「度制混框架」错误。

> **对照（本次不用，仅防混淆）**：另有「符天历·箕宿历元」变体（历元黄经取箕宿初度），以及黄道 360° 制紫气。本矛盾**不涉及**这两者。

## 3. 我方验算与矛盾（含方法与精确数字，可复现）

### 3.1 两点绝对赤道经度
- 点① 紫气 = 室宿起点 147.300 + 8.895 = **L1 = 156.195**
- 点② 紫气 = 井宿起点 256.850 + 30.240 = **L2 = 287.090**
- 两点间移动（顺行）= L2 − L1 = **130.895°**

### 3.2 儒略日（按儒略历、钟表时当 UT）
- 点① 1341-02-24 08:26 → **JD1 = 2210912.851**
- 点② 1350-03-23 20:18 → **JD2 = 2214227.346**
- Δ = **3314.494 日 ≈ 9.075 恒星年**

### 3.3 矛盾
| 检验 | 结果 |
|---|---|
| 宿距表总和 | ✅ 精确 365.25 |
| 数据裸推日行 | 130.895 / 3314.494 = **0.039492 古度/日** → 周期 **9248.8 日 = 25.32 年** |
| 授时 28 年制预测移动 | 0.0357143 × 3314.494 = **118.373°**；实测 130.895°；**差 +12.522°** |
| 29 年制预测移动 | 114.296°；差 +16.599° |
| 两点各自反推的女宿历元（授时28年制，历元 1280-12-14） | 用点① → **101.45°**；用点② → **113.97°**；**相差 12.52°（本应≈0 才自洽）** |

**结论：以现有日期，两参考点在授时 28 年制（及 29 年制）下均无法自洽。**

### 3.4 一个强线索：差值≈整 1 年
把**任一日期挪 1 年**后复算：
- 点②→1351（晚 1 年）：Δ=3679.5 日 → 日行 0.035574 → 周期 **10267 日 = 28.11 年**
- 点①→1340（早 1 年）：Δ=3680.5 日 → 日行 0.035565 → 周期 **10270 日 = 28.12 年**

即：**只要某个日期的年份差 1 年，数据几乎完美回归授时 28 年制**（10267/10270 vs 授时 10227.1792，仅差 ~0.4%，在典籍取整 + 宿距精度范围内）。故高度怀疑**其中一个日期的年份存在 1 年出入**（抄录/史料/纪年换算），或历法非儒略。

### 3.5 数据来源 = Moira 软件；其 360° 换算**不能**解释矛盾（已证）

两案例取自主流七政四余软件 **Moira** 的两个正式星案。Moira 星制度制分层：
- **内部运算与盘面显示统一用 360° 现代黄道十进制度**（swisseph 原生输出 360 黄经）；盘上看到的「女宿2度、虚6度」都是换算后的 360° 今度。
- 背后授时赤道古宿数据为 365.25 古度，Moira 用**固定系数均匀换算** `今360 = 古365.25 × (360/365.25)`，自动双向转换。
- 紫气：360° 线性计算，**基准 295°（=女宿二度）、日行 0.0352°/日**；授时原始「3分57秒14微」(365.25古度) 换算后即 0.0352°/日。

**关键证明——均匀换算不改矛盾**：把 §3.3 全部量乘 `360/365.25` 到 360° 框架：

| | 365.25 古度 | 360° 今度 |
|---|---|---|
| 两点实测移动 | 130.895° | 129.014° |
| 授时28年应移动 | 118.373° | 116.671° |
| 差 | +12.522° | +12.342° |
| 观测/预期比值 | 1.1058 | **1.1058（不变）** |

均匀换算对「实测移动」与「理论移动」乘同一系数，**比值恒定**；周期在两框架下都算成 25.32 年。故**坐标系/度制换算不是矛盾根因**，可排除。且 Moira 的 `0.0352 = 0.0357×360/365.25`、基准 `295°=女宿二度`，**确认其紫气用授时 28 年制**——反证数据裸推的 25.3 年为真实异常。
