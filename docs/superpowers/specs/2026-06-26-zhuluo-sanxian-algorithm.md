## 1. 目标

输入一张七政四余命盘，输出 **初 / 中 / 末三限** 的逐年行限，并支持 **四套交限方案**（策略可切换），最终产出三条与 UI 层约定一致的 **`SpiralSeriesSpec`**（见配套文档 §3 契约），交 `metaphysics-chart-ui` 渲染。

**职责边界**：本模块持有**全部业务规则**（三合局、昼夜、限主星、星体年数、四套交限）。chart-ui 不含任何此类逻辑；两方仅通过 `SpiralSeriesSpec` 抽象几何契约通信。

## 2. 领域模型与定数

### 2.1 限主星定取（doc1 §1）：命宫三合局 × 昼夜 → 初/中/末三主星

| 三合局 | 昼生（初/中/末） | 夜生（初/中/末） |
|--------|------------------|------------------|
| 寅午戌 | 日、木、土 | 木、日、土 |
| 亥卯未 | 金、火、月 | 火、金、月 |
| 申子辰 | 土、水、木 | 水、土、木 |
| 巳酉丑 | 金、月、火 | 月、金、火 |

- 命宫三合局：由命宫地支所属三合局判定。
- 昼夜：由生时（日出/日落）判定。

### 2.2 星体定数（doc1 §2）

| 星体 | 本宫停留年数 N | 本限标准总年限 T |
|------|----------------|------------------|
| 太阴、水星 | 1 | 24 |
| 太阳、火星 | 2 | 28 |
| 木星 | 3 | 30 |
| 金星 | 4 | 26 |
| 土星 | 5 | 26 |

> 关系恒等式：**零年顺行年数 = T − N − 20**（两节十年固定占 20 年）。
> 校验：太阴 24−1−20=3；木 30−3−20=7；日/火 28−2−20=6；金 26−4−20=2；土 26−5−20=1。

### 2.3 起宫（限本宫）
每一限的 **起宫 = 该限主星的本命本宫**（该星在命盘上的落宫），来自排盘星曜位置。三限各自独立，新限从自身起宫重起，**不承接上一限当前宫位**（doc1 §3.4）。

### 2.4 宫位/角度约定
- 十二宫索引：子=0 丑=1 寅=2 卯=3 辰=4 巳=5 午=6 未=7 申=8 酉=9 戌=10 亥=11。
- 角度：第 p 宫扇区 = `[p*30−30, p*30)`，0°=正上、顺时针为正（与棋盘其它环一致）。
- 用 chart-ui 暴露的纯函数 `sectorAngleSpan(p, 12, startOffsetDeg: -30)` 取角度，**不要**在本模块另立约定。

## 3. 单限行限算法（doc1 §2 标准走法）

给定一限：`起宫 p0`、`本宫停留 N`、`标准总年限 T`、`起始年龄 startAge`。

**标准段（四套方案在此完全一致）**：
1. **本宫静守**：`ages startAge .. startAge+N-1`，宫位恒为 `p0`，等分本宫为 N 段。
2. **顺行充满标准年限**：`ages startAge+N .. startAge+T-1`，每年顺行一宫：`palace = (p0 + (age − (startAge+N) + 1)) % 12`。
   - 该区间在古籍中区分"两节十年节点（逆数三宫速记）+ 零年顺行"，但 **note：逆数三宫仅为口算十年落点的速记，实际流年统一顺行一年一宫**。故实现上整段顺行即可。

> **古籍金标（土星，startAge=1，p0=巳=5，N=5，T=26）**：
> 1–5 守巳；6 午…15 卯（age15：5+10=palace15%12=3 卯 ✓）；25 丑（✓）；26 寅（✓）。
> 与已完成的初限渲染逐格一致。

**交限段（age ≥ startAge+T 起，四套方案分歧，见 §4）**：以"下一限起宫 `pNext`"为目标候星。

### 3.1 → 契约映射（产出 `SpiralSegment`）
- 本宫静守 N 段：`sweepDeg = +30/N`，`styleKey='zhuluo.benGong'`，`label=age`。
- 标准顺行段：`sweepDeg = +30`，`styleKey='zhuluo.lingNian'`，`label=age`。
- 交限尾段：按方案给 `styleKey`（§4）。
- `SpiralSeriesSpec.startAngleDeg = sectorAngleSpan(p0,12,startOffsetDeg:-30).startDeg`。
- `SpiralMarker`：交限发生处 `afterSegmentIndex = 该年所在段下标`，`label=下一限主星名`，`styleKey='zhuluo.transition'`。

## 4. 四套交限策略（doc2，策略接口可切换）

统一接口（伪签名）：
```
TransitionTail planTransition({
  required int p0, required int N, required int T, required int startAge,
  required int pNext,          // 下一限起宫（候星本宫）
  required int nextStarYears,  // 下一限主星的本宫停留年数（补桥公式用）
});
// 返回：交限年龄、是否成功交限、尾段 segments（含方向/样式键）、交限 marker
```

走完标准年限时，记当年宫位 `pEnd = (p0 + (T - N)) % 12`，年龄 `ageEnd = startAge + T - 1`。

### 方案1 候星逐宫延交法（A 法·古籍正统）
- 触发：**唯一**条件是行限落宫 == `pNext`；标准年限到期**不**强制换限。
- 三场景：
  1. `pEnd == pNext`：当年交限。
  2. 未到 `pNext`：从 `ageEnd+1` 起**继续顺行一年一宫**（`styleKey='zhuluo.yanJiao'`），逐年候至落宫==`pNext` 交限（可绕多圈）。
  3. 已过 `pNext`：**不折返**，继续顺行循环十二宫，下一圈重逢 `pNext` 再交限。
- 尾段：一串正 `sweepDeg=+30` 的 `yanJiao` 段，直到命中 `pNext`。

### 方案2 年限强制切换法（商用简化）
- 触发：标准年限 T 到期**直接强制换限**，不看是否到 `pNext`。
- 尾段：无延交；在 `ageEnd` 处给一个 **forced 截断**标记（`marker styleKey='zhuluo.forcedCut'`）。
- 三场景一刀切：到了=巧合同步；没到=直接切；过了=作废直接切。

### 方案3 折返补救交限法（小众私传，考据否定）
- 场景 1、2 同方案1（到则交、未到则延交顺行候星）。
- 独有场景 3：标准年限走完**已过** `pNext` → **逆行折返**倒回 `pNext` 再交限：
  - 尾段给**负** `sweepDeg=-30` 段（`styleKey='zhuluo.zheFan'`），逐宫回退至 `pNext`。
- 文档须注明：违背"零年顺转逐宫移"单向规定，主流考据派不认可；UI 以异色/虚线明示其争议性。

### 方案4 补桥年限双轨交限法（B 法·西洋改良）
- 优先触发（补桥）：若满足 **补桥公式 `剩余年限 = 宫数 × nextStarYears`**，走完补桥段刚好抵达 `pNext`，同步交限。
  - 尾段为一段/多段 `buQiao`（`styleKey='zhuluo.buQiao'`，可异色/虚线），跨多宫桥接。
  - "剩余年限/宫数"的具体取值与现有 `PeriodRingPlanner` 的 bridgeFraction 机制对齐复用（见 §6）。
- 兜底触发：不满足补桥条件 → 年限到期**强制切换**（同方案2，无无限延交）。

> 四套方案对同一盘产出**不同尾段 + 不同 styleKey + 不同 marker**；chart-ui 一视同仁照画，分歧即被可视化。

## 5. 三限串接

1. 由 §2.1 定三限主星，由 §2.3 取各限起宫 `p0_初/p0_中/p0_末` 与对应 `N、T`。
2. `初限`：`startAge=1`，按 §3 + 选定方案 §4 算到交限，记交限年龄 `ageJiao_初`。
3. `中限`：`startAge = ageJiao_初`（**交限当年即新限本宫第一年**，doc2 方案1 场景1：当年直接交限、新限从自身本宫重起），`p0=p0_中`，重走整套。
4. `末限`：同理，`startAge = ageJiao_中`，`p0=p0_末`。
5. 产出 3 条 `SpiralSeriesSpec`（id=`limit-0/1/2`），分配到 `chuxian/zhongxian/moxian` 三环带（半径由 UI 侧配置表给出，本模块不决定半径，仅给 id 与段/标记）。

> 注：三限是**年龄上顺序衔接**、**半径上三条同心环**。每限 spec 自带其年龄区间。

## 7. 金标用例（测试 fixtures）

1. **初限·土起巳（doc1 原文）**：N=5,T=26,p0=巳；断言 1–5 守巳、15→卯、25→丑、26→寅；段序列与 UI 初限一致。
2. **四方案分歧用例**：构造一个 `pEnd ≠ pNext` 且"已过 pNext"的盘，断言：
   - 方案1：尾段全为正向 `yanJiao`，绕行至 `pNext`；
   - 方案2：`ageEnd` 处 forced 截断，无尾段；
   - 方案3：尾段出现负 `sweepDeg`（折返）至 `pNext`；
   - 方案4：满足补桥公式时出 `buQiao` 段，否则 forced。
3. **限主星定取**：四局 × 昼夜共 8 组，断言三主星与 doc1 §1 表一致。
4. **恒等式**：随机星体，断言零年年数 = T−N−20。
5. **串接**：断言中限 startAge = 初限交限年龄衔接、且中限从自身起宫重起（不承接初限末宫）。
