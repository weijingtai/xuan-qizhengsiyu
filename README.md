# qizhengsiyu

七政四余排盘模块 — 中国古典星命体系的 Flutter 实现。

## 星盘制式

经调研验证，七政四余实际有效制式组合共 **7 种**（非理论 24 种）：恒星制下二十八宿锚定恒星、定义固定，无需"矫正古宿"或"今宿"；回归制下零点随岁差漂移，必须区分古宿/矫正古宿/今宿三种类型。项目已实现全部 7 种有效组合的资产文件，详见 `docs/project/research/`。
