## 1. 目标与背景

### 1.1 为什么必须用「古黄道」而非现代黄道（梅文鼎史论）

中国古代的黄道与现代意义的黄道**不同**。星命术的全力发展时代（唐宋元），用的正是古法推变的黄道；清代改用西洋新法后，宫度迁改不常，古法星命几成绝学。梅文鼎：

> 「若用新法，则宫度之迁改不常，二者已如柄（枘）凿之不相入，又安望其术之能验乎。」

**结论**：开发七政四余软件，星宿黄道度数必须走**古法推变黄道**，不能直接套现代天文黄经。本文的三种算法即古法推变黄道的三条主线。

### 1.2 项目要并存的星制表示（换算轴）

「推变黄道」历代**共同基调都是「进退」**（黄道相对赤道逐度增/减一个「黄赤道差」），三种算法只是**计算黄赤道差的方式**不同：

| # | 表示 | 计算黄赤道差的方式 | 周天 | 本文状态 |
|---|------|-------------------|------|----------|
| ① | 原生 365.25° 天赤道宿度 | 不换算（现成资产） | 365.2575 | ✅ 已有 |
| ② | **推黄道术**（第一种算法） | 大衍历**进退表**（分段线性每限增损） | 365.25/360 | ✅ 例题已验证 |
| ③ | **公式法**（第二种算法） | 姚舜辅纪元历**公式** `d=C/1000·(101−C)` | 365.25/360 | ✅ 例题已验证 |
| ④ | **弧矢割圆术**（第三种算法） | 授时历**球面三角/逐度表**（勾股+会圆术） | 365.25/360 | ✅ 例题已验证 |
| ⑤ | 等比例（朴素对照，非史法） | 线性缩放 ×360/365.25 | 360 | 平凡 |

> **拟黄道术**（民间分段多项式近似）**暂缓**：史料对其存废/算法有争议，见 §12。

## 2. 术语与三层历史关系

三种算法都属「推变黄道」，但**弧矢割圆术**是数学工具、**推黄道术**是官方工序、**拟黄道术**是民间近似，三层递进不可混：

| 名称 | 时代 | 底层数学 | 官方地位 |
|------|------|----------|----------|
| **弧矢割圆术** | 元·授时历（郭守敬/王恂，1280） | 球面勾股·弦矢弧互求（会圆术+割圆求矢） | 通用数学工具 |
| **推黄道术** | 明·大统历（沿元制） | 调用弧矢割圆算黄赤道差的完整工序（进退法） | 明代官方正统 |
| **拟黄道术** | 晚明·民间/西学过渡 | 不用弧矢，分段多项式拟合 | 民间私修 |

### 2.1 推变黄道公式的发展脉络（第二种算法的由来）

中国历法重实测，总结时表格法起大作用；但古代数学同样发达，遂逐渐出现**公式**总结黄赤道换算：

- 自一行**大衍历**，进退之法已成定调（→ 第一种算法）。
- 唐末**边冈**贡献很大，设计出好公式，但繁复。
- 北宋相继改进：宋行古**崇天历** → 周琮**明天历** → 皇居卿**观天历** → 姚舜辅**纪元历**（公式误差最少）。
- 后代沿用不弃：南宋赵知微**大明历**、元耶律楚材**庚午历**。
- 故**第二种算法选用姚舜辅纪元历的公式法**。

### 2.2 需修正的两处既有代码错误

1. `zhou_tian_model.dart` 中 `EquatorialToEcliptic` 注释「推黄道术，又称拟黄道术」**错误**（该类是现代球面三角 `atan2`；推黄≠拟黄）。正确定位：弧矢/推黄的**现代 ε 校验参照**。
2. `example/assets/qizhengsiyu/yuan_shoushi_chidao_hengxin.json` 命名「天赤道 365.25」但宿度合计为 **360**（自相矛盾，疑误放投影后黄道表），需厘清标注。

## 3. 进退加减总则（三算法共用框架）

无论用哪种方式算 `d`（黄赤道差），加减规则相同：

- **以两分为定点、向两至方向（45°内）：黄道比赤道增度** → `黄道度 = 赤道度 + d`；
- **以两至为定点、向两分方向（45°内）：黄道比赤道减度** → `黄道度 = 赤道度 − d`。

即：两分到两至黄道增益、两至到两分黄道减损。`d` 在象限两端（分/至）为 0，象限中点（赤道≈45.66°）最大。某宿黄道距度 = 该宿首尾两点黄道积度之差（跨分/至时按外量取和）。

## 4. 第一种算法：大衍历进退表法（→ 推黄道术）

### 4.1 黄赤道度差主表（大衍历，分母 24）

节点（赤道度 → `d`，度）：

```
 5→0.500  10→0.958  15→1.375  20→1.750  25→2.083  30→2.375
35→2.625  40→2.833  45→3.000  46.31→3.000
51.31→2.833  56.31→2.625  61.31→2.375  66.31→2.083
71.31→1.750  76.31→1.375  81.31→0.958  86.31→0.500  91.3125→0
```
每限增损数：`+12,+11,+10,+9,+8,+7,+6,+5,+4`（到45/46.31），`0`，`−4…−12`。象限内不足 5 度的余量线性插值：`d(a)=d(节点)+每限增损×(余量/5)`。最大 `d`=**3°**（现代实测 2.5°，古法过冲）。完整三历（乾象/皇极/大衍）见[附录 A](#附录-a表-1-18-三历黄赤道度差表)。

## 5. 第二种算法：姚舜辅纪元历公式法

### 5.1 公式

北宋姚舜辅纪元历，已知赤道度 `C` 求黄赤道差：

```
黄赤道差  d = (10·C / 10000) · (101 − C) = C/1000 · (101 − C)         （式 2-85）
```

**界定（把 C 折到升段 [0, 45.65]）**：
- `C < 45.65545`：直接代入；
- `45.65545 < C < 91.3109`：以 `91.3109 − C` 代入；
- `C > 91.3109`：以 `182.6218 − C` 代入。

加减规则同 §3（春分起加、夏至/冬至起减）。若嫌 45.65545 折返繁复，可直接按「以两分为定点向两至 45° 用加、以两至为定点向两分 45° 用减」判定符号。

### 5.2 验证（例题逐位复现，春分设在壁 0°）

- 壁宿：`C=8.6`，`d=8.6/1000·(101−8.6)=`**0.7946**，黄道`=8.6+0.7946=`**9.3946**（原文 0.7964/9.3946）。
- 奎宿末：`C=25.2`，`d=1.9102`，黄道积度`=27.1102`（原文 27.1105）。
- **奎宿黄道距度 = 27.1102 − 9.3946 = 17.7155°**（原文 17.7156；授时表值 17.87）。

## 6. 第三种算法：授时历球面三角 / 弧矢逐度表

### 6.1 数学本质与逐度表

元授时历用勾股 + 沈括会圆术（≈球面三角）算黄赤道差，并**细列逐度表**（各度黄道积度、度率、黄赤道差）。元史云「依表而推」但未收录该表；**该表收于《明史·大统法原》**。用表规则同 §3（两分到两至加、两至到两分减）；因传抄或有误，用时宜上下左右互校。逐度表前 16 度节选见[附录 B](#附录-b授时历逐度黄赤道差表明史大统法原节选)。

### 6.2 现代等价：反 RA（供软件精算）

授时表等价于球面三角。软件里可用现代式精算：

```
正向（已有 HushiGeyuan）:  tan α = cos ε · tan λ
反向（宿度换算需补）:      λ = atan2( sin α , cos α · cos ε )
```

⚠ **易错点**：`cos ε` 在**分母侧**（乘 `cos α`）。误写成分子侧（`atan2(sinα·cosε, cosα)`）会方向相反（角宿收窄、井宿变宽）。自检口诀：**角宿扩张、井宿收窄**。授时 ε=23.90°，最大 `d`≈**2.5°**。需给 `HushiGeyuan` 补 `inverseRightAscension(α)`（象限内单调，二分求解+四象限对称+零点偏移）。

### 6.3 验证（逐度表例题逐位复现，春分设在壁 6°）

- 壁右段：`C=8.6−6=2.6`，黄道`=黄道(2)+0.6段=2.1728+0.6+0.6·(0.2588−0.1728)=`**2.8244**（原文 2.8244）。
- 奎宿末：离春分`=2.6+16.6=19.2`，黄道`=20.4872+0.2+0.2·0.0622=`**20.6996**（原文 20.69964，用表19度=20.4872/度率0.0622）。
- **奎宿黄道距度 = 20.6996 − 2.8244 = 17.8752°**（原文 17.87524；授时给定 **17.87**）✓。
