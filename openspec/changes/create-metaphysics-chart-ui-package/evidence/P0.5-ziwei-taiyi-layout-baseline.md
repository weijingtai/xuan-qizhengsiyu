## ZiWeiDouShu

### ChartGrid (chart_grid.dart:22, 240 lines)
- 4×4 Row/Column widget grid, 12 PalaceCard widgets on perimeter
- Center 4 cells merged into 命主/身主 + 四化 info panels
- Layout pattern:
```
巳  午  未  申
辰  [命主]  酉
卯  [四化]  戌
寅  丑  子  亥
```
- NO CustomPaint/Canvas — pure widget composition
- Imports: `package:ziwei/domain/models/chart_result.dart`, `package:theme/theme.dart`

### PalaceCard (palace_card.dart:1, 251 lines)
- Individual rounded-rectangle card per palace
- Shows: palace name, gan-zhi, main stars, minor stars, sihua badges, decadal age
- Uses `AnimatedContainer` with `BorderRadius.circular`

## TaiYiShenShu

### TaiYiPanGridV2 (taiyi_pan_grid_v2.dart:11, 317 lines)
- Concentric rounded-rect board using CustomPaint with `_TaiYiPanPainterV2`
- Four concentric shapes: outer rect → 3 RRect rings (R1/R2/R3) → center circle (R4)
- 16 gods in middle ring, 9 luoshu numbers, 8 gates
- Inner `GridView.count` (line 110) as transparent touch overlay for 9 palace taps

## Neutral Model Mapping

- ZiWei 12 perimeter → `CellLayer` with 12 ChartSector (perimeterSlot) + center Widget via `BoardCenterSpec`
- TaiYi Legacy 16 gods → rounded-rectangle perimeter with 16 ordered slots; this is the parity target
- TaiYi optional circular projection → `SectorLayer` with 16 equal sectors over the same ordered `ring16Gods` data; this is an alternative renderer, not a claim about the Legacy geometry
- TaiYi 9 palaces → `CellLayer` with 9 ChartSector (row/column, 3×3)
- PieSegmentPainter → `CircularCanvasBoard` arc rendering
- TwentyEightStarsCircle → `TickLayer` / `ArcLayer`

## Boundary Decision

The package must preserve the source data order independently from geometry.
`ring16Gods` may therefore be projected to either a 16-slot rounded perimeter
or a 16-sector circle without changing the TaiYi domain model. Visual parity
tests must use the rounded-perimeter projection; circular rendering is opt-in.
