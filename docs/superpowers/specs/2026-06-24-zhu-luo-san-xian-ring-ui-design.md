# 竹罗三限环形 UI 设计与可行性分析

## 状态

- 讨论结论已确认。
- 本文只定义 UI 投影与绘制，不改变竹罗三限计算。
- OpenSpec change：`render-zhu-luo-san-xian-rings`。
- 实现前仍需用户审核 OpenSpec 与实施计划。

## 设计结论

竹罗三限不是完整年龄圆环，而是三组稀疏行限轨迹：

```text
由内向外：
初限·首次入宫
初限·第二次入宫（有则绘制）
初限·第三次入宫（有则绘制）
中限·首次入宫
中限·第二次入宫（有则绘制）
末限·首次入宫
末限·第二次入宫（有则绘制）
```

初限、中限、末限是三个语义环组。重复入宫会在所属环组外侧增加物理子环，但只绘制发生重复的宫位。

## UI 必须表达的特点

| 特点 | UI 表达 |
|---|---|
| 三限分层 | 初限在内、中限居中、末限在外 |
| 稀疏落宫 | 未经过的宫位保持透明 |
| 停宫多年 | 宫位30度按停留年数等分年度格 |
| 跳宫 | 来源与目标之间绘制跳转连接；中间宫不着色 |
| 重复入宫 | 增加所属限的重复访问子环 |
| 补桥 | 保持真实逐年宫位，使用桥接样式 |
| 交限 | 只保留一个年度格，使用跨环交限标记 |
| 算法扩展 | UI只消费年度结果，不识别A、B或自定义算法 |

## 绘制前的数据投影

```text
List<ZhuLuoYearResult>
  -> 连续访问片段
  -> 每限访问层
  -> 每宫年度格
  -> 跳转/交限连接
```

连续记录只有在以下字段完全相同且年龄连续时才合并：

```text
stage + ruler + palace + phase + usedBridge
```

任一字段变化都开始新的访问片段。

## 几何规则

### 环半径

```text
trackInnerRadius =
  baseRadius
  + 前序限组总轨道宽度
  + 当前限访问序号 × (trackWidth + repeatGap)
```

限组之间使用 `stageGap`，同一限的重复环之间使用更小的 `repeatGap`。

### 宫位角度

```text
palaceStart = chartOffset + palaceIndex × 30°
palaceSweep = 30°
```

### 年度格

一次连续停宫 `N` 年：

```text
cellSweep = 30° / N
cellStart(i) = palaceStart + i × cellSweep
cellEnd(last) = palaceStart + 30°
```

最后一个格强制贴合宫界，避免浮点累计缝隙。

## 年龄文字

默认使用 `rangeOnly`：

- 单年显示 `19`。
- 多年显示 `5–14`。
- 只在访问片段的中央格显示一次。
- 其他年度格仍然绘制、可点击、可读语义。

保留：

- `allCells`：每格显示单岁，文字放得下才绘制。
- `auto`：正常比例显示范围，放大后切换逐岁。

切换文字模式不得改变格子数量、几何、ID或点击区域。

## 颜色与线条

- 分格线必须是浅色主题分隔线，不使用黑色。
- 初限、中限、末限使用不同语义色。
- 重复环沿用所属限颜色，通过透明度或明度区分。
- 补桥使用独立语义样式。
- 跳转线与交限标记使用独立语义样式。
- 不在几何或 Painter 中硬编码 ARGB。
- 颜色不能是唯一编码：重复环、补桥、跳线、交限还需要点线、虚线、纹理、边界刻痕或形状差异。
- 必须测试语义样式确实被消费：只改变 stage/bridge 语义角色时，弧段样式或 golden 输出必须变化。
- 明暗主题都要有证据，不能只验证浅色主题。

## 技术方案

年度格使用现有 `metaphysics_chart_ui`：

- 每个访问轨道对应一个 `ArcLayer`。
- 每个年度格对应一个 `ArcSegment`。
- 复用现有浅色分隔、标签锚点、主题和按弧点击区域。

跳转线不能使用当前的 `OverlayLayer`，因为其圆形布局和 Canvas Painter 尚未实现。首版采用七政侧的 `ZhuLuoTransitionPainter`，只绘制跳宫线和交限标记，不绘制年度格、文字或点击区域。

## 可行性

### 当前可以直接实现

- 动态多环半径。
- 宫位稀疏弧段。
- 宫内年度格。
- 浅色分格线。
- 默认范围文字与可选逐岁文字。
- 每个年度格独立点击。
- 初、中、末与补桥主题样式。

### 需要新增七政侧能力

- 年度结果压缩与重复入宫编号。
- 动态轨道半径规划。
- 年度格到 `ArcLayer` 的转换。
- 跳宫和交限连接层。
- Radio算法选择与标签密度控制。
- 选中年度格后的详情数据。
- 小角度年度格的宽容选择：hit slop、先选访问片段再选年份、触摸放大或同等交互。
- 线性年度路径列表：年龄、阶段、宫位、phase、跳转、补桥、交限，必须与环图来自同一个几何计划。

### 允许修改的样式边界

- `lib/painter/chart_style/qi_zheng_chart_style.dart`
- `lib/painter/chart_style/theme_chart_style_resolver.dart`
- 现有七政本项目主题 token 文件

不得为了样式角色修改 `../metaphysics-chart-ui/`。

### 本次不修改

- `calculateZhuLuoSanXian`。
- A/B算法配置。
- 洞微大限与百六限。
- 飞限与小限。
- 数据库存储。
- `metaphysics_chart_ui` 包。

## 主要风险

1. 重复入宫过多导致半径不足：提前计算轨道数量；不足时明确报错，禁止丢数据。
2. 逐岁文字拥挤：文字可以隐藏，但格子、点击和语义不可消失。
3. 跳转线与弧段错位：两者必须消费同一个不可变几何计划。
4. 交限年龄重复：年度格只能有一个，交限通过元数据和连接标记表达。
5. 旧环图被误复用：禁止依赖 `DaXianRingPainter` 和 `DaXianCalculateHelper`。
6. 投影层重算规则：禁止重新去重、补年或调用竹罗规则 helper；输入年度记录数必须等于年度格数。
7. 样式假完成：必须证明语义角色改变会改变渲染输出。
8. 移动端触摸：小角度格不可要求精确点击。
9. 可访问性：生产启用前必须有非颜色编码和线性列表 fallback。

## 验收摘要

- 初、中、末径向顺序正确。
- 重复入宫环插入所属限组内。
- 每次停宫完整占据本宫30度并按年等分。
- 未经过宫位透明且不可点击。
- A法跳过的宫位不显示为经过。
- B法补桥显示真实年度格。
- 交限年龄不重复。
- 默认范围文字清晰，放大后可逐岁显示。
- 小年度格可被宽容选择。
- 线性列表与环图 payload 一致。
- 明暗主题均可读。
- 无黑色硬边、无skip/only测试、无旧大限计算泄漏。
